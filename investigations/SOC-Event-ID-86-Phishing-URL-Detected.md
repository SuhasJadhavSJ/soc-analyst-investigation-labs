# EVENT ID : 86 - Phishing URL Detected

## 1. Executive Summary
- **Verdict:** True Positive (Malicious Credential Harvester)
- **Severity:** HIGH
- **Status:** Closed / Remediated
- **Summary:** Internal Workstation `EmilyComp` (`172.16.17.49`) initiated an outbount connection on Port 80 to the external host (`91.189.114.8`) attempting to access a targeted credential  phishing page hosted on a compromised wordpress environment. The web proxy allowed the outbound request. Threat Intelligence analysis confirmed the landing URL is malicious with a 100/100 threat score. Workstation isolation was executed via EDR, malicious network artifacts were cataloged for edge blocking, and identity remediation was initiated for the targeted user.

## 3. Investigation Playbook & Triage Steps 

### Step 1: Ingestion & Initial Scoping
- **Ticket Ingestion:** Claimed and initiated active investigation for Event ID 86 in Case Management.
- **Initial Telemetry Assessment:**
  - Network egress event generated by internal workstation `EmilyComp` (`172.16.17.49`).
  - Perimeter policy registered `Device Action: Allowed`, confirming connection establishment through the web gateway.
  - Initial alert flagged the traffic under rule `SOC141 - Phishing URL Detected`.

### Step 2: Telemetry Correlation & Log Inspection
- Executed search in Log Management targeting source address `172.16.17.49` and destination address `91.189.114.8`.
- Discovered 2 correlated events:
  - **Firewall Log (`2021-03-22 23:53:16`):** Outbound TCP connection from `172.16.17.49:55662` to `91.189.114.8:80` permitted.
  - **Proxy Log (`2021-03-22 23:53:54`):** HTTP request permitted to requested URI:
    `hxxp[://]mogagrocol[.]ru/wp-content/plugins/akismet/fv/index.php?email=ellie%40letsdefend.io`
- Evaluated the URI parameters: URL utilizes an Akismet plugin path on a Russian domain (`.ru`) with pre-populated URL encoding for targeted internal user `ellie@letsdefend.io`.

### Step 3: Threat Intelligence Verification
- Conducted external detonation lookup on Hybrid-Analysis for target URL:
  - **Threat Score:** 100 / 100 (Malicious)
  - **Indicators:** 58 Total (5 Malicious, 13 Suspicious, 40 Informational)
  - **Payload Signature:** Credential-harvesting landing page leveraging masqueraded WordPress plugin paths.

### Step 4: Endpoint Inspection & Scope of Impact
- Accessed EDR console under Endpoint Security for asset `EmilyComp` (`172.16.17.49`).
- Confirmed web browser execution initiated communication to destination IP `91.189.114.8`.
- Reviewed active processes, terminal history, and local file changes:

## 6. Containment & Remediation Actions Taken
1. **EDR Host Isolation:** Applied network containment to host `EmilyComp` (`172.16.17.49`) via Endpoint Security to prevent potential callback operations or lateral persistence.
2. **Perimeter Defense:** Forwarded destination IP `91.189.114.8` and root domain `mogagrocol.ru` to network security engineering for perimeter firewall drop rules and proxy categorization blocking.
3. **Identity Securing:** Initiated password reset and revoked active session tokens for user `ellie@letsdefend.io` due to exposure on an external harvesting interface.
4. **Threat Intelligence Submission:** Added identified IOCs into the internal threat database.
